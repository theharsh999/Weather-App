# Weather App 🌦️

A simple and clean Weather Application built using **HTML, CSS, and JavaScript**.  
The app fetches real-time weather data using the **OpenWeather API** and displays it on the screen.

## 🌐 Live Demo
👉 https://theharsh999.github.io/Weather-App/

---

## 🚀 Features
- Search weather by city name
- Displays:
  - City name
  - Temperature (°C)
  - Feels like temperature
  - Humidity
  - Wind speed
- Press **Enter** or click button to search
- Clean and modern UI
- Error handling for invalid city names

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript (DOM, Events, Async/Await)
- Axios (for API requests)
- OpenWeather API

## 🔑 API Used
- **OpenWeather API**
- Endpoint: https://api.openweathermap.org/data/2.5/weather

---

## ▶️ How to Run Locally
1. Clone the repository
2. Open `index.html` in a browser
3. Enter a city name
4. Click **Get Weather** or press **Enter**

## 📌 Notes
